ABOUT (description):
Star Citizen AFK helper for Windows in a HUD look. Always shows a countdown of the game's AFK window with an adjustable warning tone. Optional mouse PULSE (ARMED/OFF) nudges 3 px only while the game is in focus. PULSE OFF = monitor-only, no input sent, for players who want to respect CIG's ToS. Single exe, no dependencies.
